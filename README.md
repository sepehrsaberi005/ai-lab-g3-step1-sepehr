## ۳. ساختار پوشه‌بندی مخزن (Folder Hierarchy)
```text
.
├── step1/                      # پوشه تمرین و گام اول (تگ step1)
│   ├── check_env.ipynb         # تست وابستگی‌ها
│   ├── city_router_grid.ipynb  # شبیه‌سازی شبکه ۲ بعدی
│   └── README.md
│
├── step2/                      # پوشه تمرین و گام دوم (تگ step2)
│   ├── lab2_pathfinding.ipynb  # نوت‌بوک جستجوی مسیر و چالش هزینه معابر
│   ├── maps/                   # فایل‌های JSON نقشه و متادیتا
│   └── README.md
│
├── step3/                      # پوشه تمرین و گام سوم (تگ step3)
│   ├── lab3_nim_minimax_eda.ipynb # نوت‌بوک کلاسی Nim با چالش B هوشمند
│   ├── city_router_eda.ipynb   # نوت‌بوک EDA روی دیتاست پروژه مسیریاب شهری
│   ├── data/                   # فایل‌های داده CSV
│   │   ├── nim_games.csv
│   │   ├── nim_smart_b_games.csv
│   │   └── city_router_dataset.csv
│   ├── README.md               # گزارش جامع تحلیل آماری و نمودارها
│   └── notes/                  # یادداشت‌های تحلیلی تخصصی این عضو
│
├── requirements.txt            # پکیج‌های پایتون
├── .gitignore                  # نادیده‌گیری فایل‌های زائد
└── README.md                   # راهنمای کلی مخزن
```
