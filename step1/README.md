## ۲. مشخصات فنی پیاده‌سازی شبیه‌ساز (`city_router_grid.ipynb`)

در این گام، تمرین کلاسی جاروبرقی ۴ اتاقه یک‌بعدی بر اساس نیاز پروژه به یک محیط دوبعدی ارتقا یافت:

```python
# معماری هسته شبیه‌ساز دوبعدی
actions = {
    "Up":    (-1, 0),
    "Down":  (1, 0),
    "Left":  (0, -1),
    "Right": (0, 1)
}
```

### عامل‌های پیاده‌سازی‌شده:
1. **عامل تصادفی (`RandomAgent`):**  
   مسیرهای آزاد مجاور را استخراج کرده و به صورت رندوم یک جهت مجاز را انتخاب می‌کند.
2. **عامل واکنشی ساده (`ReflexAgent`):**  
   فاصله منهتن تا مقصد را محاسبه کرده و حریصانه بهترین جهت کاهنده فاصله را برمی‌گزیند.
3. **عامل مبتنی بر مدل (`ModelBasedAgent`):**  
   دارای حافظه کوتاه‌مدت (`visited set`) است؛ تقاطع‌های دیده شده را فیلتر کرده و در صورت امکان از ورود مجدد به مسیرهای طی‌شده و بن‌بست‌ها اجتناب می‌کند.

## ۳. جدول PEAS و ویژگی‌های محیط

| مؤلفه | شرح پیاده‌سازی در کد |
| :--- | :--- |
| **معیار کارایی (P)** | محاسبه امتیاز در هر گام بر مبنای نزدیکی به مقصد و پاداش سرعت |
| **محیط (E)** | ماتریس دوبعدی ۶×۶ با موانع بولی (`numpy.ndarray boolean mask`) |
| **محرک‌ها (A)** | بردار جابجایی سطر و ستون در ۴ جهت اصلی |
| **حسگرها (S)** | تابع بازگرداننده موقعیت فعلی، وضعیت موانع خانه‌های مجاور و فاصله تا مقصد |

- **ویژگی‌های محیط:** مشاهده‌پذیری جزئی | قطعی | دنباله‌ای | ایستا | گسسته | تک‌عاملی.
